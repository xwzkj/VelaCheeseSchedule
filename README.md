# 奶酪课程表（Vela）

给小米 Vela 手表用的课程表快应用。课程配置保存在手表本地，首页显示当天安排和倒计时，上下课时按设定振动提醒，课表可以通过 Android 连接器导入。

核心逻辑移植自桌面版奶酪课程表，手机连接器负责把 JSON 配置或 CSES 课表同步到手表。连接器没有开源，本项目是手表端源码；连接器和构建产物可以在[下载页](https://schedule.wanzii.cn/doc/download.html)获取。

## 项目亮点

### 打开就能看到这节课

首页把当前课程、下一节和剩余时间放在最显眼的位置。进行中的课程会自动滚进视野，课名太长时滚动显示，课间也能显示休息倒计时。

### 息屏后也能提醒

上下课切换时可以振动提醒，提供轻柔、标准、强提醒三种模式。开启提醒后，应用会申请后台保活，尽量保证息屏状态下的提醒仍然有效。设置页可以直接预览振动效果，切换后实时生效。

### 配置从手机同步

连接器支持标准桌面端 JSON 配置和 CSES YAML。选择文件或直接粘贴 CSES 内容后，连接器会检查版本、字段和课程数量，再通过设备通道发送。手表保存成功后会提示重启，重新打开即可使用新课表。

### 课表逻辑按实际使用来做

课程引擎支持单双周、起始周设置、时间偏移等功能。学校铃声和手表时间有偏差时，可以按秒调整。

## 功能

| 模块 | 功能 |
| --- | --- |
| 今日课程 | 当前时间、日期、当前课程、下节课、剩余时间 |
| 整周课表 | 按课表和星期切换，查看每天课程，点击进入课程详情 |
| 课程详情 | 显示课程名称、上课时间、教室、教师、课程状态、进度和剩余时间 |
| 振动提醒 | 上下课振动，支持轻柔、标准、强提醒和效果预览 |
| 起始周设置 | 指定本周对应第几套课表，自动计算后续周次 |
| 时间偏移 | 正数延后，负数提前，单位为秒，用于校准上课时间 |
| 课表管理 | 使用内置默认课表，或清除手表上的课表配置 |
| 配置同步 | 接收手机连接器发送的 JSON 配置或 CSES 课表，保存到本地 |

## 使用方式

### 同步课表

1. 在手机上安装并打开奶酪 Vela 连接器。
2. 选择 JSON 配置文件，或选择、粘贴 CSES YAML 课表。
3. 连接器校验通过后，点击同步到手环。
4. 手表提示配置更新成功后，重启手表端应用。

连接器需要手环设备管理权限。手环未连接时，请先在小米运动健康中完成连接。

仅 CSES 配置支持教师、教室信息

### 手表端设置

在手表应用底部进入关于页，再打开设置，可以修改以下内容。

| 设置项 | 说明 |
| --- | --- |
| 起始周设置 | 选择本周对应的课表周次 |
| 震动提醒 | 打开或关闭上下课提醒，并选择振动模式 |
| 时间偏移 | 调整课程状态和倒计时使用的当前时间 |
| 使用默认课表 | 恢复项目内置的示例课表 |
| 清除课表配置 | 删除本地保存的课表配置 |

## 开发

项目使用 Vela 快应用工具链，`deviceTypeList` 只包含 `watch`。

```bash
npm install
npm run start
```

构建和发布。

```bash
npm run build
npm run release
```

代码检查。

```bash
npm run lint
```

提交前会通过 husky、Prettier、ESLint、Stylelint 和 commitlint 处理格式与提交信息。首次使用需要关联 Git，然后执行：

```bash
./husky.sh
```

## 项目说明

手表端代码主要由 AI 参与编写，核心逻辑从桌面版奶酪课程表移植而来。桌面版由人类开发，手机连接器目前为私有项目，未开放源码。

连接器与手表端必须使用相同的通信协议版本。当前版本为 2，配置同步完成后需要重启手表端应用。
